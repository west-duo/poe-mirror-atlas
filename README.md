# Mirror Atlas (미러 아틀라스)

Path of Exile / Path of Exile 2 의 아이템을 검색하고, 보상·전리품 화면을 읽어 **시세를 게임 위에 겹쳐 보여 주는**
Windows 오버레이입니다. 이 저장소는 설치 파일을 공개 배포하는 곳이며, 소스 코드는 공개하지 않습니다.

## 내려받기

[Releases](../../releases) 페이지에서 `Mirror-Atlas-Setup-<버전>.exe` 를 받아 실행합니다.

- Windows 10/11 (x64). 관리자 권한 없이 사용자 폴더에 설치됩니다.
- 코드 서명 전이라 Windows SmartScreen 경고가 뜰 수 있습니다. 「추가 정보 → 실행」 으로 진행합니다.
- 받은 파일이 올린 파일과 같은지는 릴리즈의 `SHA256SUMS.txt` 로 확인할 수 있습니다.

## 이 앱이 하지 않는 일

| 하지 않는 것 | |
|---|---|
| 게임 프로세스 메모리 읽기·쓰기 | 하지 않습니다 |
| 키보드·마우스 후킹, 코드 주입 | 하지 않습니다 |
| 게임 패킷 가로채기·조작 | 게임 트래픽을 보지 않습니다 |
| 자동화 루프·봇 동작 | 키 입력은 사용자 입력 1회당 1회입니다 |
| 계정 자격증명 취급 | `POESESSID` 등 세션 쿠키를 요구하지도 저장하지도 않습니다 |

화면은 캡처해 OCR 로 읽기만 합니다.
